Customer sends a message
        ↓
Meta sends it to your server through a webhook
        ↓
Your bot checks the message and conversation history
        ↓
Find an answer from FAQs, business data, or AI
        ↓
Send the reply through Messenger’s Send API
        ↓
Save the conversation for future replies

A webhook is a public HTTPS endpoint that receives incoming messages from Meta.

FILES AND THEIR WORK

main.py
Creates the FastAPI app, defines webhook and health routes, and starts/stops resources.

techrock/config.py
Loads environment variables from the root .env file and defines the project root path.

techrock/db/database.py
Creates the MySQL database and missing tables; manages the SQLAlchemy engine and sessions.

techrock/db/models.py
Defines the jobs and history database tables using SQLAlchemy ORM models.

techrock/db/storage.py
Saves incoming messages, selects queued jobs, stores replies/history, and manages retry status.

techrock/services/chatbot.py
Uses LangChain and Groq to generate replies from knowledge.txt and conversation history.

techrock/services/messenger.py
Sends text replies to Messenger users through Meta's API.

techrock/services/worker.py
Processes queued messages, generates/sends replies, retries failures, and expires old messages.

techrock/__init__.py, techrock/db/__init__.py, techrock/services/__init__.py
Mark these folders as Python packages so their modules can be imported.

tests/test_webhook.py
Tests webhook verification, signatures, duplicate protection, ignored events, and reply processing.

tests/__init__.py
Marks the tests folder as a package for test discovery.

knowledge.txt
Stores verified information about The Tech Rock for the chatbot's answers.

.env
Stores actual API keys, Meta settings, and MySQL credentials; keep it private.

.env.example
Provides configuration variable names and example defaults without real secrets.

requirements.txt
Lists the Python dependencies needed to run the project.

.gitignore
Prevents secrets, virtual environments, caches, and local data from being tracked by Git.

README.md
Explains installation, configuration, running the app, testing, and current limitations.

workflow.txt
Describes the message workflow and each project's file responsibilities.
